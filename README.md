# ♟️ IndiChess Backend

IndiChess Backend is a **Spring Boot REST API** that powers the IndiChess application.  
It handles user management, authentication, game data, and backend business logic for the chess platform.

---

## 🚀 Features

- RESTful APIs using Spring Boot
- User authentication & authorization
- Backend support for chess-related operations
- Clean layered architecture (Controller, Service, Repository)
- Maven-based project structure
- MySQL database integration
- Exception handling & validations

---

## 🛠️ Tech Stack

- **Java**
- **Spring Boot**
- **Spring Web**
- **Spring Data JPA**
- **MySQL**
- **Maven**
- **Hibernate**
